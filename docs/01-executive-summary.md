# LoopedIn — Executive Summary

## One-line vision
A private, event-centered social app for families and friend groups that turns planning life together into shared memories.

## The opportunity
The current market is fragmented:
- calendar apps are practical but emotionally flat
- family organizer apps are useful but often dated
- private photo apps preserve memories but do not coordinate life
- group chats coordinate life poorly because everything gets buried

LoopedIn sits in the whitespace between these categories.

## Product thesis
If people already plan life in one app, chat in another, and store memories in a third, there is an opportunity to create a better daily-driver product by anchoring all three around the event.

In LoopedIn, every event becomes a durable shared object:
1. plan it
2. discuss it
3. get reminded about it
4. attend it
5. add photos and reactions
6. revisit it later as a memory

## Target users
### Primary
- young families
- parents coordinating with partners and extended family
- close friend groups
- couples graduating from simple shared calendars

### Secondary
- roommates
- hobby/social clubs
- recurring trip groups
- multi-generational families

## Core differentiation
- **private by default** instead of public/follower-first
- **event-native** instead of feed-native or chat-native
- **photo-rich** instead of purely utility-focused
- **daily practical** instead of novelty social
- **premium interaction design** instead of legacy organizer UX

## Why this could win
Most competitors choose one side of the market:
- organizers handle logistics
- memory apps handle photos
- chat apps handle communication
- event apps handle invites

LoopedIn can win by making the event the bridge between utility and emotion.

## Recommended wedge
Start with **private group event planning + shared albums + contextual chat**.

This wedge is narrow enough to ship, but broad enough to prove the core habit loop:
- check what is coming up
- react to changes
- coordinate in context
- capture the moment
- return later for memories

## MVP outcome to validate
A household or friend group should be able to say:
> “We actually use this every week to know what’s happening, talk about it, and keep the photos in one place.”
