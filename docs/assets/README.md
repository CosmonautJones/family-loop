## Cover generation prompt

Built-in image generation; no external image API script or additional image service was used. The final prompt was:

> Create a finished, premium GitHub README cover banner for a private family calendar app named LoopedIn. Wide landscape 1536x1024 or widest supported composition, with all essential artwork in central wide band suitable as a repository hero. Warm editorial paper illustration, refined Scandinavian magazine art direction, cream background #FBF7F2, dark plum #71345E, muted terracotta, peach and sage accents. Clean generous whitespace, subtle paper texture, confident adult visual taste. Left half: large beautifully typeset exact title 'LoopedIn', beneath it exact tagline 'Shared plans. Lasting memories.' Small uppercase text above title 'A PRIVATE SPACE FOR YOUR PEOPLE'. Right half: elegant illustrative arrangement of a desk calendar with abstract unnumbered grid, two overlapping photographic-style illustrated keepsake prints of a lakeside picnic and a family dinner viewed from afar, and one flowing plum thread looping through all three objects. Generic illustrated people small and faceless; no real people, no private content. The thread is a quiet metaphor for plans becoming memories, no arrows, no software UI mockups, no badges, no fake features, no app-store logos, no security claims. Highly legible restrained typography; polished composition that fits a cream and plum family coordination brand. Only the exact specified text. Avoid gradients, glowing tech, 3D plastic, childish cartoons, busy decoration. Save finished project asset.
