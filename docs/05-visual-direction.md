# Family Loop — Visual Direction

## Design north star
**Warm premium utility**

Family Loop should feel like a blend of:
- Apple Photos / Calendar polish
- Instagram’s confidence with media
- Partiful’s event energy
- a private, intimate, low-pressure social environment

The goal is not to feel like a noisy social network or a cold enterprise planner. It should feel like the place your people actually keep life together.

---

## Brand feeling
The app should communicate:
- closeness
- trust
- elegance
- modernity
- lightness
- usefulness

### Tone words
- intimate
- polished
- playful in small moments
- calm
- emotionally warm
- never chaotic

---

## Product experience principles

### 1. Practicality is the baseline
Users need to know what is happening fast.

### 2. Photos give the product emotional gravity
Memories should be integrated naturally into the event lifecycle.

### 3. Motion should explain hierarchy
Transitions should make navigation feel spatial and premium.

### 4. Color should be intentional, not loud
Use a calm neutral system with memorable accent colors.

### 5. Private social should feel different from public social
No vanity metrics overload. No noisy content incentives.

## Visual system direction

### Base palette
Use warm neutrals and charcoal rather than stark white/black extremes.

Suggested foundation:
- porcelain off-white
- mist gray
- soft charcoal

### Accent palette
Suggested primary and support accents:
- deep mulberry
- coral
- sage
- sky blue or butter as secondary event accents

### Rationale
Mulberry gives distinctiveness and premium warmth. Coral adds social energy. Sage adds softness and trust.

---

## Typography direction

### Primary UI face
A clean sans such as Inter or SF-style system typography.

### Optional accent face
A restrained serif for invitation titles, memory recap moments, or special events.

### Hierarchy
- large editorial titles for events and home hero modules
- medium semibold for activity cards and event metadata
- compact utility text for scheduling details

Typography should carry a lot of the premium feeling.

---

## Layout strategy

### Home
A hybrid surface rather than a single feed.

Recommended sections:
- next event hero
- recent moments
- activity updates
- upcoming agenda
- resurfaced memory

### Event detail
Event detail should act like a living room for the gathering.

Recommended structure:
- cover or collage
- title / date / location
- RSVP actions
- attendee strip
- logistics card
- event conversation
- shared album grid
- post-event recap or memory module

### Calendar
The app should support:
- month view
- agenda view
- event drill-down with rich transitions

Add subtle visual cues for dates with memories or events.

---

## Motion system

### Principles
- fast
- soft
- tactile
- spatially meaningful

### Recommended transitions
- day tile morphing into event detail
- event hero collapsing into sticky header
- thumbnail-to-gallery shared element transitions
- RSVP microanimations
- memory recap card reveal transitions

### Microinteractions
- avatar stacks animating when attendance changes
- chips/pills with satisfying active states
- elegant upload progress
- subtle celebratory reactions on milestone moments

Motion should make the app feel premium without becoming distracting.

---

## Component direction

### Cards
Three primary card families:
- media cards
- utility cards
- activity cards

### Chips and pills
Use rounded tactile chips for:
- RSVP state
- filters
- tags
- event status

### Avatars
Avatars should be prominent in attendees, chat, reactions, and group identity.

### Sheets and modals
Use soft partial sheets for quick actions and immersive full-screen flows for creation or galleries.

---

## Screen concepts to prioritize

### 1. Home dashboard
A premium hybrid of planning and memory.

### 2. Event detail page
The centerpiece of the entire product.

### 3. Calendar-to-event transition
This is likely the signature interaction.

### 4. Create event flow with live invitation preview
Makes the product feel crafted and social.

### 5. Shared album / recap screen
Critical for emotional retention.

---

## Anti-patterns to avoid
- crowded productivity UI
- over-gamified social interactions
- excessive gradient/noise everywhere
- scrapbook kitsch
- public-social metric clutter
- animation that slows practical tasks

---

## Final style statement
Family Loop should look and feel like a private, premium social calendar for real life: calm enough for daily planning, expressive enough for celebrations, and beautiful enough that people want to keep their memories there.
