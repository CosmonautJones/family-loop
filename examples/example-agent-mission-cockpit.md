# Example: Agent Mission Cockpit

## Vision

A developer-native app that turns rough ideas into agent-ready build missions with acceptance criteria, anti-goals, risks, and test plans.

## Sharp wedge

Not a generic AI task manager. It is a mission-shaping cockpit for developers using Claude Code, Cursor, Codex, and local AI.

## Enemy

- vague prompts
- generic AI apps
- forgotten context
- agent work that cannot be reviewed
- building before the product idea is sharp

## Core loop

```text
Rough idea -> product critique -> sharpened mission -> implementation prompt -> review checklist -> completed agent-ready task
```

## Magic moment

The user pastes a messy idea and gets a clean current mission, anti-goals, acceptance criteria, and a builder prompt in under two minutes.

## First mission

Build a single-page local app where the user can paste a rough idea and generate:

- sharp wedge
- anti-goals
- first mission
- acceptance criteria
- builder prompt
- QA checklist

Do not build auth, storage sync, teams, billing, or dashboards.
