# Example Current Mission

## Mission

Build the first-run flow that turns one rough app idea into an agent-ready mission pack.

## Business / product reason

This is the core value of the app. If this does not feel useful, no other feature matters.

## User story

As a developer with a rough idea, I want to turn it into a clear agent-ready mission, so that I can hand it to Claude Code or Cursor without getting generic output.

## Acceptance criteria

- [ ] User can paste a rough idea.
- [ ] App outputs a sharp wedge.
- [ ] App outputs anti-goals.
- [ ] App outputs current mission.
- [ ] App outputs acceptance criteria.
- [ ] App outputs a builder prompt.
- [ ] App does not require auth.
- [ ] Empty state explains what to paste.

## Do not touch

- Auth
- Billing
- Teams
- Settings
- Persistent cloud sync

## Definition of done

- [ ] First-run flow works locally.
- [ ] Output is copyable.
- [ ] UX feels specific, not generic.
- [ ] Review log updated.
