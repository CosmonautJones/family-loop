# Apply Project Profile Prompt

Use this when starting a new project or converting an existing app to the harness.

```text
Read the selected project profile:

project-profiles/[PROFILE_NAME].md

Then update these files for my specific app idea:

docs/vision.md
docs/core-loop.md
docs/taste-bar.md
docs/anti-goals.md
docs/architecture.md
evals/product-rubric.md
tasks/current-mission.md

My app idea:

[PASTE APP IDEA]

Rules:
- Do not write implementation code yet.
- Make the idea sharper and less generic.
- Use the profile as a starting point, not a cage.
- Define one tiny first mission.
- Add anti-goals that prevent feature creep.
- Make the current mission suitable for Claude Code or Cursor.
- Keep the first slice useful before auth, billing, teams, settings, or dashboards unless truly required.
```
