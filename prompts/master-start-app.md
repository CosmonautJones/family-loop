# Master Start App Prompt

I want to build a genuinely useful app, not a generic AI-generated MVP.

Your first job is NOT to code.

Act as a senior product founder, UX lead, and software architect.

Help me turn this idea into a sharp buildable app:

```text
[PASTE IDEA]
```

Create or update these docs:

1. `docs/vision.md`
- What this app is
- Who it is for
- What pain it attacks
- Why it should exist
- The sharp wedge
- The enemy
- Success criteria

2. `docs/core-loop.md`
- The one repeatable action that creates value
- The first 60-second user experience
- The magic moment
- The repeat trigger
- What must feel excellent before new features

3. `docs/taste-bar.md`
- What the app should feel like
- What it should avoid
- Reference products
- Anti-generic rules

4. `docs/anti-goals.md`
- Features we are not building yet
- Generic SaaS bloat to avoid
- Things that would make the app mediocre

5. `tasks/current-mission.md`
- The smallest excellent first slice
- Acceptance criteria
- Files likely involved
- Test plan
- Definition of done

Do not write implementation code yet.
Be opinionated.
Cut weak ideas.
Make the app sharper.
